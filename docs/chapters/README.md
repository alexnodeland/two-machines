# Chapter planning documents

One document per page in
[Information architecture](../architecture/information-architecture.md), following the
template in [Content methodology §3](../architecture/content-methodology.md#3-chapter-template).
This is the per-chapter planning pass that Plan-001 Phase 0 calls for — the level of
detail between the one-table page specification and the MDX itself.

These are **planning documents, not prose drafts**. Sentences that appear here may be
promoted into chapters, but nothing here is published as written.

Written in the [§7 writing order](../architecture/content-methodology.md#7-writing-order),
not chapter order — Part I first, because writing the thesis chapter is the real test of
the argument.
